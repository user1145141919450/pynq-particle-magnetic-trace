# 《磁场粒子对战》PC 原型

纯软件的玩法验证版：先在电脑上把规则、手感、数值调通，再谈上板。

## 运行

```bat
cd E:\pynq-magnetic-field-demo\game_pc
set PYTHONPATH=E:\py_pkgs\vision
python main.py
```

截图自检（不开窗口，渲染一张 PNG）：

```bat
python main.py --shot render\shot.png          :: 局前阶段
python main.py --shot render\shot.png play     :: 对战阶段
python main.py --shot render\shot.png edit     :: 改磁场暂停
```

物理引擎自检（含"乌龙球"规则校验）：

```bat
python engine.py
```

## 键位（一把键盘，左右分区，零重叠）

| 功能 | 选手一（左手区） | 选手二（右手区） |
|---|---|---|
| 调入射角 | `W` / `S` | `↑` / `↓` |
| 调速度 | `A` / `D` | `←` / `→` |
| 发射 | `空格` | `回车` |
| 选球色 | `Z` 红 / `X` 蓝 | `,` 红 / `.` 蓝 |
| 改磁场（全局暂停） | `Q` | `/` |
| 局前：选道具 / 购买 | `W`/`S` / `E` | `↑`/`↓` / `*` |
| 局前：去布置或就绪 | `空格` | `回车` |
| 改磁场时 方向 / 大小 / 确认 | `W`/`S`、`A`/`D`、`E` | `↑`/`↓`、`←`/`→`、`*` |
| 通用 | `T` 轨迹束、`H` 按键调试、`R` 重开、`ESC` 退出 | 同左 |

**摆球**：先按选色键选红/蓝，再用鼠标点自己的边界（PC 原型里"鼠标点击"就是相机识别摆球的替身）。

## 已实现（对照 `docs/game_rules_quickref.md`）

- 分块磁场（整场划分为 n 块，第 n 局 n 块，封顶 9 块），圆弧拼接运动、圆角边界反弹
- 同极弹性碰撞、异极湮灭、实体障碍反弹、成对传送门（带禁放区）
- 洞口判定 + **只能进对面那侧的洞**（自己那侧按墙处理，防乌龙球）
- 30 秒无进球 → 洞口朝落点热点移动（含"不让玩家一调就进"的三道刹车）
- 10 局制 + 平局自动加赛；积分与五种道具；局前购买与布置
- 轨迹束（发射点附近扇形 + 临界高亮）、虚线预览、最后 5 秒洞口提醒
