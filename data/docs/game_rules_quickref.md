# 《磁场粒子对战》规则速查表 v5（2026-10-07 修订）

> **v5 改动（用户拍板，覆盖 v4 的“进球即止”）**：
> **① 进球只得分、不停局**——本局继续打，没进的球继续弹，一局可进多球；
> **② 本局结束 = 双方弹药（各 3红2蓝）打光 + 5 秒落定**（落定期间进球照算）；
> **③ 结算 = 冻结全场球的运动；上一局还在飞的球，下一局原轨迹续飞**——
> 它们记着发球人，之后进洞仍算原发球人的分。

> v4 改动：**选手二选块键改为小键盘 `.`**、**改磁场触发全局暂停（粒子冻结、双方禁发射）**、
> 输入框改为整数输入（不再需要小数点，键位冲突消除）。

## 0. 一句话
两位选手把带电小球放在**红色场区内任意位置**发射（2026-10-28 起不必贴边；方向 =
**界面绝对角：0°=右水平、逆时针为正、360°一圈**），穿过分块磁场区，把球送进对面边界的洞口得分；十局定胜负。

## 2. 一局时间轴

| 阶段 | 内容 |
|---|---|
| **局前阶段** | **第 1 局跳过**（双方 0 积分，无可买可布置）。第 2 局起：① 购买道具（用积分）　② **电脑设置本局磁场（n 块）与洞口**　③ 布置：摆实体障碍物、放置传送门　④ 双方确认 → 本局开始 |
| **局中** | 随时可发起 **改磁场**（`Q`/`.`) 与 **加洞口**（`C`/`;`），两者都触发全场暂停 |
| **对战阶段** | 任意时刻摆球发射；粒子场内运动；**改磁场可随时发起（触发全局暂停，见 §7）** |
| 30 秒无进球 | 洞口朝该侧"命中热点"移动，计时重置（暂停期间计时冻结） |
| 判定 | 有人进洞 → +10 分（**本局继续**，v5）→ 双方弹药打光 +5s 落定 → 结算（冻结/续局，v5）→ 下一局局前阶段 |

> **传送门与实体障碍物只在局前布置，开局后不可再动**；加洞口也只在局前完成。

## 3. 判定表

| 事件 | 结果 |
|---|---|
| 粒子中心越过边界，落点在洞口范围内 | **进洞：+10 分（本局继续，v5）**（洞口闪光 + 板载 LED 绿灯） |
| 粒子中心越过边界，落点在洞口外 | 镜面反射，继续飞行 |
| 撞实体障碍物 / 撞圆角 | 按对应法线反射 |
| 红 ↔ 蓝 相碰（球心距 < 22 px） | **双方湮灭消失** |
| 红 ↔ 红 / 蓝 ↔ 蓝 相碰 | 弹性反弹（同性相斥） |
| 进入传送门 | 从配对门穿出，**速度大小与方向不变** |
| 本局结束 | 场上剩余粒子全部清场 |

> **电荷与磁场**：红 = 正电、蓝 = 负电——在场内受洛伦兹力，**同一块磁场里异号偏转
> 方向相反**（红与蓝的轨迹互为镜像）；未知色 = 中性，不偏转（走直线）。

## 5. 胜负

- 每局（v5）：进球都算分、一局可多球；**双方弹药打光 +5 秒落定后本局结束**；在飞的球下一局续飞、进球记原发球人
- 总胜负：10 局后总得分多者胜；平局加赛一局
- 10 局结束：进球多的一方获胜；总分平局加赛一局

## 6. 键位映射（一把键盘，左右分区，零重叠）

### 6.1 对战阶段

| 功能 | 选手一（左半区） | 选手二（右半区） |
|---|---|---|
| 入射角 − / + | `S` / `W` | `↓` / `↑` |
| 速度 − / +（步进 20 px/s；游戏像素/秒） | `A` / `D` | `←` / `→` |
| 发射 | `空格` | `回车` |
| 选红球（+1） | `Z` | `,`（或小键盘 `0`） |
| 选蓝球（−1） | `X` | `.`（小键盘 `.`） |
| 发起改磁场（全场暂停） | `Q` | `/`（小键盘 `/`） |
| 发起加洞口（全场暂停） | `C` | `+`（小键盘 `+` 或 Shift+=） |

- **摆球**：按选色键选好红/蓝 → 鼠标点自己那侧（PC 原型；上板后 = 把实体球放在**红色场区内任意位置**由相机识别；不必贴边，球身压着场区即可）
- **球色实时跟随选择**：摆好球之后还能随时换色，屏幕上的球立刻变色
- 该色球用完时面板会把色块置灰并标"（用完）"；本局球全打完则显示"本局球已打完"，且不能再摆球

| 功能 | 选手一 | 选手二 |
|---|---|---|
| ① 购买：上下选道具 | `W` / `S` | `↑` / `↓` |
| ① 购买：买下当前道具 | `E` | `*` |
| ② 进入布置（或直接就绪） | `空格` | `回车` |
| ③ 布置：移动光标 | `W A S D` | `↑ ↓ ← →` |
| ③ 布置：切换待放置道具 | `Q` | `/` |

### 6.3 改磁场（局中，全场暂停）

| 功能 | 选手一 | 选手二 |
|---|---|---|
| 连按 = 循环选块 → 确认锁定 | `Q` → `E` | `/` → `*` |
| 磁场方向 ±（出屏 ⊙ / 入屏 ⊗） | `W` / `S` | `↑` / `↓` |
| 磁场大小 ±（步进 0.2，范围 0.5~3.0） | `A` / `D` | `←` / `→` |
| 确认完成并恢复对战 | `E` | `*` |
| 取消（自动还原原值） | `ESC` | `ESC` |

### 6.4 加洞口（局中，全场暂停，四条边都能放）

| 步骤 | 选手一 | 选手二 |
|---|---|---|
| 连按 = 切换边界（上→右→下→左） | `C` | `+` |
| 确定这条边 | `E` | `*` |
| 微调位置（左右边用上下键；上下边用左右键，每按 10 px） | `W`/`S` 或 `A`/`D` | `↑`/`↓` 或 `←`/`→` |
| 放置 | `E` | `*` |
| 取消 | `ESC` | `ESC` |

- 位置非法（太靠角、与同边已有洞口重叠）时预览条**变红**且放不下
- 该洞的归属方 = 加洞的玩家（只有他的球能进，对对手仍是墙）

### 6.5 通用键

| 键 | 作用 |
|---|---|
| `T` | 轨迹束开关（发射点附近的半透明扇形 + 临界高亮） |
| `H` | 按键调试：显示最后收到的键码（排查按键不灵用） |
| `R` | 局中/局前 = 重开本局；结算画面 = 重开整场 |
| `ESC` | 退出游戏（在"改磁场 / 加洞口"里第一次按是取消该操作） |

> **防误触原则**：一把键盘两个人用，任何一方的按键都落在自己那半区、两方键位互不重叠。
> 选手一选球色用 `Z`/`X`（贴 WASD 左下角）而**不用数字键**，避免与选手二的小键盘数字混淆。
> **数值输入框已取消**：角度/速度只用按键步进调整（2° / 20 px·s⁻¹）。
> **角度口径（2026-10-28）**：0°=右水平、逆时针为正（90°=上，180°=左，270°=下），
> 按 360° 环绕；**速度单位 = 游戏像素/秒（px/s）**。
> 上板后键位不变，只把 `/` `*` `+` `.` `,` 换成真正的小键盘按键（板子读 `/dev/input`，小键盘与主键盘可区分）。

### 6.4.1 加洞口细则（补充）

- **触发**：选手一按 `C`、选手二按 `+`（小键盘 `+` 或 Shift+=）（本局还有免费额度 / 道具 / ≥30 分）
- **全场暂停**：粒子冻结、双方不能发射、30 秒计时冻结
- ① 连按触发键**切换边界**（上 → 右 → 下 → 左，四条边都能放）
- ② 按确认键（`E` / `*`）**确定这条边**
- ③ 用**两个键**微调位置（左右边界用 `W/S` 或 `↑/↓`；上下边界用 `A/D` 或 `←/→`），每按一次移动 10 px
- ④ 再按确认键**放置**；`ESC` 取消
- 位置非法（太靠角、与同边已有洞口重叠）时预览条变红并拒绝放置
- **该洞的归属方 = 加洞的玩家**（只有他的球能进；对对手仍是墙）
- **只接受当前操作者的按键**，另一方误触不会把洞口挪走

### 6.2.1 局前阶段细则（补充）

| 步骤 | 选手一 | 选手二 |
|---|---|---|
| 在道具清单里上下选择 | `W` / `S` | `↑` / `↓` |
| 购买当前选中的道具 | `E` | `*` |
| 进入布置阶段（或直接就绪） | `空格` | `回车` |
| 布置：移动光标 | `W A S D` | `↑ ↓ ← →` |
| 布置：切换"待放置的道具" | `Q` | `/` |
| 布置：确认放置 | `E` | `*` |
| 双方都按了就绪 → 本局开始 | — | — |

- **加球道具语义**：每购买 1 次 = **本局红球 +1、蓝球 +1**（一次性，本局结束失效）
- **障碍物**：放置后**永久保留**（后续每局都在场上）；原型默认 160×20 横条（上板后由相机识别实际形状与角度）
- **传送门**：连放两次成一"对"（第一端 + 第二端）；与任何洞口距离必须 > 场区宽度 1/5（192 px）；**永久保留**
- **加洞口**：只能加在**对方那侧**边界（= 自己的靶区）；每人初始免费 1 次；**仅本局有效**
- **改磁场**：局前买、局中随时可用（触发全局暂停），每次消耗一次购买次数

## 7. 全局暂停（改磁场 / 加洞口）—— 两者互斥

> **互斥规则**：同一时刻**只允许一项暂停类操作**（改磁场 或 加洞口）。
> 先发起者优先；另一方这时按自己的键会被**忽略并提示**"对方正在进行XX，请稍候"。
> 必须等前一项**确认或取消**（全场恢复）之后，才能发起另一项。
> 屏幕顶部横幅会常驻提示这条规则，两侧玩家都能看到。

## 7.1 改磁场

1. **触发**：玩家按下选块键（选手一 `Q` / 选手二 小键盘 `.`），且本局还有"改磁场"使用次数
2. **暂停期间**：
   - **场上所有粒子冻结**（位置、速度、方向全部保持）
   - **双方都不能发射**（摆球也不生效）
   - 30 秒洞口计时冻结
   - 屏幕提示"选手 X 正在调整磁场"，被选中的块高亮闪烁
3. **操作**：同键循环选块 → 方向键/WASD 调方向与强度 → 确认键**结束并恢复**；取消键放弃修改并恢复
4. **恢复**：全场从冻结状态继续（粒子沿原轨迹接着飞）
5. **防滥用**：每次暂停消耗一次"改磁场"购买次数；**单次暂停最长 30 秒**，超时自动确认并恢复（修改保留）

## 8. 洞口自适应规则（30 秒防僵局）

1. 局内每 30 秒计时重置一次（暂停期间冻结）
2. 计时到点：统计该侧边界上**本局累计的全部粒子落点**，找出命中最密集的位置
3. 洞口朝该密集区中心移动一小步：
   - 单次移动 ≤ 1.5 倍洞宽（66 px）
   - 目标位置带 ±15 px 随机偏移（不对准最优点）
   - **若移动会让当前正在飞行的粒子在 2 秒内直接进洞 → 本次移动作废**
   - 移动后不能与其他洞口重叠；距边界端点 ≥ 1 个洞宽
4. 两侧独立、对称移动

## 9. 物理与数值

| 项 | 值 |
|---|---|
| 半径公式 | r(px) = v(px/s) ÷ B（k = 1 s） |
| 速度大小 | 恒定（磁场不做功，只改方向） |
| 入射角范围 | ±90°（合计 180°），以边界法线为 0° |
| 角度步进 | 2°（输入框 1°） |
| 速度范围 | 200 ~ 600 px/s，默认 400 |
| 速度步进 | 20 px/s（输入框 1 px/s） |
| 磁场强度范围 | 每块 0.5 ~ 3.0，方向 = 出屏 / 入屏 |
| 半径对照 | v=400 时：B=0.5 → r=800（缓弯）、B=1 → r=400、B=3 → r=133（急弯） |

## 10. 界面布局与实现要点

```
┌──────────── 顶部 HUD 90px：局数 / 30秒倒计时 / 比分 ────────────┐
│ 选手一面板 160px │                                 │ 选手二面板 160px │
│  · 比分          │         场区 960×540             │  · 比分          │
│  · 道具栏        │   （圆角矩形 3×3 磁场块，        │  · 道具栏        │
│  · 角度输入框    │    双方边界各有洞口）            │  · 角度输入框    │
│  · 速度输入框    │                                 │  · 速度输入框    │
└──────────── 底部 HUD 90px：提示 / 操作提示 ────────────────────┘
```

**实现要点**
- 轨迹：跨块时方向连续、曲率突变 → "圆弧拼接"；暂停时冻结粒子状态即可，恢复后续算
- 分块：递归对半切割得到若干矩形（x0,y0,x1,y1 + 有符号 B）；"在哪一块" = 逐个矩形包含判断（最多 9 块，线性扫描足够）
- 几何复用：圆—线段求交、相切判定、首交点角序（同 `geometry.py`）
- 三色判定：绿 = 穿出 / 橙 = 临界相切 / 红 = 折返打回
- PL 侧：① 视觉流水线（只向 ARM 传坐标与颜色）；② 多轨迹并行求解与临界筛查（轨迹束）
- ARM 侧：磁场与球体运动解算、洞口与得分判定、洞口自适应、暂停状态机、道具与人机交互
- 摄像头职责：球坐标 + 颜色（红/蓝 = 电荷，黑 = 洞口标记）+ 实体障碍物位置与形状
