# 提交前检查表模板

> 用法：复制到你的项目，逐项打勾；任何“否”都不提交。
> 对应赛方 3.3.5.1 工程包 / 3.3.5.2 技能包 / 3.3.5.3 设计报告 / 3.3.5.4 目录规范。

## 1. 工程包（3.3.5.1）

- [ ] 完整源码：RTL / HLS / PS 软件（按实际实现方式）
- [ ] 仿真/验证结果：测试台、期望值、运行记录
- [ ] 综合与实现报告：资源占用、时钟频率、关键性能指标（原始 .rpt）
- [ ] 上板工程、运行脚本、实测输出与参考结果比对
- [ ] 可复现构建脚本：从零构建 + 改 RTL 重建 + 时序门禁
- [ ] 构建脚本在**干净目录**（只拷源码、无 proj/）跑通过
- [ ] 关键 bug 修复有对应测试/回归

## 2. 技能包（3.3.5.2）

- [ ] `skill/README.md` 存在
- [ ] 每项写清：适用范围、使用方法、失效条件、已验证效果、来源失败
- [ ] 可复用：陌生队伍能直接套用（脚本/模板/提示词）
- [ ] 通用 PYNQ Skill（如适用，单独加分）
- [ ] 不含真实凭据/口令

## 3. 设计报告（3.3.5.3）

- [ ] 选题背景与创新点（解决什么问题、前人做过什么）
- [ ] 设计原理与功能框图
- [ ] 软硬件划分依据与接口设计
- [ ] 优化过程 + 优化前后性能/资源对比表（每行写口径）
- [ ] 大模型协作记录：提示词、模型回答、自我纠错轨迹、智能体工作流
- [ ] 技能包提炼过程（从哪些失败/观察、怎么验证、边界）
- [ ] 从零复现步骤（可执行到“出 bit/上板/台架”）
- [ ] 负结果/边界如实写
- [ ] 所有数字有出处（文件/日志/命令）

## 4. 目录/命名（3.3.5.4）

- [ ] 目录/文件名纯英文小写（数字/下划线/连字符）
- [ ] 无中文目录名、无空格、无特殊字符
- [ ] README 给出目录对照（若未用推荐结构）
- [ ] 推荐结构映射：src/sim/build/board/data/skill/report（或说明）
- [ ] 不提交：proj/、.cache/.gen/.runs、xsim.dir、__pycache__、*.wdb/jou/pb、
      *.TIMING_FAILED、.git、备份/大文件
- [ ] 提交包大小合理（非源码重物已排除）

## 5. 安全/合规

- [ ] 无 GitHub 令牌 / WiFi 口令 / 板卡密码 / 私钥
- [ ] 无本机绝对路径（D:/、F:/、C:/）出现在可执行脚本（注释可 WARN）
- [ ] 第三方 IP/代码许可兼容（MIT/Apache-2.0 等）
- [ ] 板卡型号、工具版本已在报告中声明
- [ ] 如使用非推荐工具版本，报告中有说明 + 复现保证

## 6. 最后三件事

- [ ] `python tools/check_submission_ready.py` → 0 ERROR
- [ ] 上板复跑关键台架（V3/PE/检测/画线/帧泵）并保存原始日志
- [ ] 提交包解压到干净目录，按 README 从零构建一次（或至少 bd_only）
